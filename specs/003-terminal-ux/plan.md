# Implementation Plan: Terminal UX Enhancements

**Branch**: `003-terminal-ux` | **Date**: 2026-04-14 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/003-terminal-ux/spec.md`

## Summary

Bring the in-game terminal in line with real-world terminal-emulator conventions:
auto-scroll to the latest output line (fix existing partial implementation), Tab-key
command autocomplete against the registered command registry, and Up/Down arrow
command history navigation with a 50-entry session cap. All three features are
implemented as targeted additions to existing classes (`TerminalOutputView`,
`TerminalController`, `CommandParser`) plus one new model (`CommandHistory`).

## Technical Context

**Language/Version**: C# 9 (.NET Standard 2.1, Unity 6 scripting runtime)
**Primary Dependencies**: Unity 6 (6000.4.2f1), TextMeshPro, Unity Input System, Unity Test Framework (NUnit)
**Storage**: N/A — history is session-only, no persistence changes
**Testing**: Unity Test Framework — edit-mode (CommandHistory, CommandParser) + play-mode (scroll coroutine, key interception)
**Target Platform**: PC (desktop keyboard required for Tab and arrow-key features)
**Project Type**: Unity game (idle / incremental)
**Performance Goals**: All terminal interactions MUST resolve within a single frame; scroll deferred to end-of-frame to avoid mid-frame layout spike; no GC allocations in the Tab/Up/Down hot path
**Constraints**: 22.22 ms frame budget (Constitution Principle IV); no `Canvas.ForceUpdateCanvases()` in hot paths
**Scale/Scope**: ~10 registered commands; history cap 50 entries; 3 UI scripts modified + 1 new model

## Implementation Phases

### Phase 1: CommandHistory Model (foundational, no UI dependency)

New pure C# class. Edit-mode testable independently of Unity scene.

Key design:
- `List<string> _entries` — newest appended to end
- `const int MaxEntries = 50`
- `int _navIndex = -1` — −1 means "not navigating"
- `Add(string)`: append + cap + reset `_navIndex`
- `NavigateBack()`: decrement `_navIndex` (clamp 0), return entry (null if empty)
- `NavigateForward()`: increment `_navIndex`; if past end, reset to −1, return null
- `ResetNavigation()`: set `_navIndex = -1`

### Phase 2: CommandParser — GetRegisteredVerbs

Minimal addition to existing class:

```text
public IReadOnlyList<string> GetRegisteredVerbs()
{
    var verbs = new List<string>(_registry.Keys);
    verbs.Sort(StringComparer.Ordinal);
    return verbs;
}
```

Allocates one `List<string>` per call — acceptable since autocomplete is player-triggered,
not a per-frame hot path.

### Phase 3: TerminalOutputView — Deferred Scroll Fix

Replace:
```text
private void ScrollToBottom()
{
    Canvas.ForceUpdateCanvases();                  // ← REMOVE
    _scrollRect.verticalNormalizedPosition = 0f;
}
```

With:
```text
private bool _scrollPending;

private void ScrollToBottom()
{
    if (_scrollPending || _scrollRect == null) return;
    _scrollPending = true;
    StartCoroutine(ScrollAtEndOfFrame());
}

private IEnumerator ScrollAtEndOfFrame()
{
    yield return new WaitForEndOfFrame();
    _scrollRect.verticalNormalizedPosition = 0f;
    _scrollPending = false;
}
```

Add `using System.Collections;` to the file.

### Phase 4: TerminalController — Key Handling + History Wiring

Add `Update()` to `TerminalController`:

```text
private CommandHistory _history = new CommandHistory();

private void Update()
{
    if (!_inputField.isFocused) return;

    var kb = UnityEngine.InputSystem.Keyboard.current;
    if (kb == null) return;

    if (kb.tabKey.wasPressedThisFrame)        HandleTab();
    if (kb.upArrowKey.wasPressedThisFrame)    HandleHistoryUp();
    if (kb.downArrowKey.wasPressedThisFrame)  HandleHistoryDown();
}
```

`HandleTab()` logic:
1. Read `_inputField.text.Trim()`.
2. Get `verbs = GameManager.Instance.CommandParser.GetRegisteredVerbs()`.
3. Filter verbs that start with the prefix (case-insensitive).
4. 0 matches → no-op.
5. 1 match → set `_inputField.text = match`; move caret to end.
6. 2+ matches → `_outputView.AppendLine(string.Join("  ", matches))`.
7. Re-focus input field after any action.

`HandleHistoryUp()` / `HandleHistoryDown()`:
- Call `_history.NavigateBack()` / `NavigateForward()`.
- If result is non-null → set `_inputField.text = result`; move caret to end.
- If result is null → `_inputField.text = string.Empty`.

Update `OnSubmit()`:
- Before clearing the field, call `_history.Add(input.Trim())`.

Tab focus retention (prevent EventSystem navigation on Tab):
```text
// At end of HandleTab():
UnityEngine.EventSystems.EventSystem.current.SetSelectedGameObject(null);
_inputField.ActivateInputField();
```
